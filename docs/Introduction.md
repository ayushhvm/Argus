# Introduction
CineSeek is a modern Information Retrieval platform specifically designed for movie discovery. It demonstrates the evolution from traditional Lexical matching to advanced Semantic Search and Hybrid Reciprocal Rank Fusion (RRF).

# Problem Statement
Traditional movie search relies heavily on exact keyword matching, failing to capture user intent. Users often search for concepts (e.g., "movies about time travel") rather than exact titles.

# Objectives
1. Implement and evaluate Lexical (TF-IDF) retrieval.
2. Implement and evaluate Semantic (FAISS) retrieval using sentence transformers.
3. Fuse both approaches using RRF.
4. Provide an intuitive, production-ready interface.
